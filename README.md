# Mail Merge Project - Parents Invitation Letters

## 📖 Project Overview
This is my first IT project created for automating parents invitation letters using Mail Merge feature in Microsoft Word and Excel.

Instead of typing 100+ letters one by one, this project uses one template and automatically generates personalized invitations for each parent.

## 🛠️ Tools Used
- Microsoft Excel - for parents data (Name, Student Name, Class, Phone)
- Microsoft Word - for invitation letter template
- Mail Merge - to connect Excel data with Word template

## 📁 Files in this Repository
- `Parents_Invitation_Main...` - Main Word document with mail merge fields
- Excel file with parents list
- Final merged invitation letters

## ✨ How It Works
1. Created parents database in Excel
2. Designed invitation template in Word
3. Connected Excel to Word using Mail Merge (Mailings > Start Mail Merge)
4. Inserted Merge Fields: <<Parent_Name>>, <<Student_Name>>, etc.
5. Finished & Merged to generate all letters at once
